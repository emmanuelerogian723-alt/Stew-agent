Quick Start
Make your first API call in seconds:
# Install requests
pip install requests

# Make a chat request
import
requests
resp = requests.post(
  "https://stew-agent.onrender.com/chat",
  json={"message": "Hello STEW!"}
)
print(resp.json()["response"])
Or with curl:
curl -X POST \
  https://stew-agent.onrender.com/chat \
  -H "Content-Type: application/json" \
  -d '{"message":"Hello!"}'
