01Quickstart

Register once, get your key instantly, make your first call in under a minute. No card required.

# 1. Get your free API key
curl -X POST https://stew-agent.onrender.com/auth/register \
  -H "Content-Type: application/json" \
  -d '{"name":"Your Name","email":"you@example.com","password":"secret123"}'

# → {"api_key":"stew_xxxxx...", "plan":"free", "calls_limit":1500}
# 2. Make your first AI call
curl -X POST https://stew-agent.onrender.com/chat \
  -H "Content-Type: application/json" \
  -d '{"api_key":"stew_xxxxx","message":"Write a one-line pitch for a Lagos fintech app"}'

Check your usage any time

curl "https://stew-agent.onrender.com/usage?api_key=stew_xxxxx"
→ {"plan":"free","cycle":{"used":3,"limit":1500,"remaining":1497,
     "resets_at":"2026-10-01T00:00:00Z","period":"monthly"}, ...}

02Authentication

Every request authenticates with your S.T.E.W API key. Pass it as api_key in the request body or query string. Keys start with stew_.

Your key is visible on the dashboard and via GET /auth/me. Rotate it any time with POST /auth/regenerate-key. Never commit it to source control.

04OpenAI-Compatible Endpoint

Anything built for OpenAI works with S.T.E.W — just change the base URL and the key. Migrate an entire app in one line.

# Instead of:  OPENAI_BASE_URL=https://api.openai.com/v1
# Use:        OPENAI_BASE_URL=https://stew-agent.onrender.com/v1

from openai import OpenAI
client = OpenAI(api_key="stew_xxxxx",
                base_url="https://stew-agent.onrender.com/v1")

r = client.chat.completions.create(
    model="gpt-oss-120b",
    messages=[{"role":"user","content":"Translate to Yoruba: Good morning, boss"}])
print(r.choices[0].message.content)

08Rate Limits & Quotas

Limits are monthly, generous, and always visible — in the response body, in standard headers, and on demand via GET /usage. No surprises.

Cycles reset on the 1st of each month. Plans run in 30-day cycles from purchase. When your allowance runs out, S.T.E.W Coins keep you running automatically — see below.
