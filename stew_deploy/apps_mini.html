1
Connect an app

Open an app card, tap Connect, and finish the provider’s secure OAuth page.

2
Ask naturally in chat

STEW checks the real connection and discovers the current tool schema. It does not guess tool names.

3
Review the prepared action

Reading and analytics run immediately. Sending, posting, uploading, editing, deleting, booking, and payments wait.

4
Approve or cancel

Reply APPROVE to run exactly the prepared action, or CANCEL to discard it. For a cross-app goal use /goal followed by the outcome, then watch Goals for progress. Provide a timezone for future schedules.

Security: connections are isolated by authenticated Telegram user ID. Passwords stay with the provider. STEW records app activity and never treats an unverified browser user ID as identity.
