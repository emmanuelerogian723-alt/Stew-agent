1
Connect an app

Open an app card, tap Connect, and finish the provider’s secure OAuth page.

2
Ask naturally in chat

STEW checks the real connection and discovers the current tool schema. It does not guess tool names.

3
STEW just does it

Reading, analytics, sending, posting, uploading, editing, and booking all run immediately once you ask clearly — your request IS the approval.

4
One confirm for permanent deletes

Only a permanent delete/remove pauses and asks first, since that can't be undone. Reply APPROVE to go ahead, or CANCEL to discard it. For a cross-app goal use /goal followed by the outcome, then watch Goals for progress. Provide a timezone for future schedules.

Security: connections are isolated by authenticated Telegram user ID. Passwords stay with the provider. STEW records app activity and never treats an unverified browser user ID as identity.
